Architecture

One narrow judgment inside a code-owned loop

The raw snapshot remains the safety authority. The compact projection is only Jev input.

Design decision

Remove persistent profiles from the default path

Persistence is extra risk without proven generic value.

Chosen · deterministic generic state

  • Current AX snapshot + permitted actions
  • Goal-aware structural projection
  • In-memory delta within one run
  • Works on the first visit to a site

Rejected · origin or URL-family cache

  • Can mix unrelated pages
  • Adds privacy and invalidation concerns
  • Needs unreliable family inference
  • Makes new sites second-class
Execution

Ten independently testable phases

Each phase has a red test, minimal implementation, verification, and a conventional commit.

Generic contract

Five unrelated fixtures and a runtime test that forbids Agoda-specific branches.

AX parser

Lossless source lines, indices, roles, names, ancestry, and origin validation.

Projection

Protected actions, relevant structure, bounded text, and generic deltas.

Readiness

Actionable-state polling, no-action detection, and candidate ceilings.

Orchestration tests

Staleness, confidence, injection, retries, handoffs, and verification.

Packaging

Documentation

Compatibility

One-release migration

profileCacheDir and profileCacheEnabled remain accepted but become ignored and documented as deprecated. Existing callers keep working while the runtime stops reading or writing profiles.

Rollback

Commit-sized reversibility

Record the starting commit, preserve the dirty worktree, and revert only a failed phase. Never reset or clean unrelated work. Restore the installed skill from a clean checkout of the last release.
